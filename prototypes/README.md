# 日历便签 · 首屏原型对比

双击同目录的 `CalendarMemo-Designs.html`。可以并排看三版，或切到单张、按实际尺寸查看。三版使用同一组虚构便签，比较的是工作区布局；原型内的新增、编辑和筛选控件仅展示位置与状态，不读写正式记录。

| 方向 | 首屏先看到什么 | 主要取舍 |
| --- | --- | --- |
| 01 月历总览（推荐） | 7 列 × 6 行的完整月历，底部展开当天事项 | 最方便从整月找空档，也保留原有“选日期再记”的习惯。单个日期只能放短摘要。 |
| 02 当日清单 | 当天的时间线、未定时间事项和快速记录表单 | 适合早上打开就看今日安排。月历保留日期和忙闲提示，不展开每格文字。 |
| 03 四象限台 | 四象限矩阵和本日／本月／本季度／本年 | 适合排优先级和做周期回顾。完整月历通过顶栏进入。 |

三版都以简体中文的 Windows 桌面视口为准（1440×900），使用系统字体和内联图标，没有网络依赖。当前原型为静态首屏，未加业务交互、动效或移动端版式；确认方向后再落地到正式应用。

方向与六行月历、时间线及双轴矩阵通过独立文字评审。实屏由制作方自查；本轮为方向探索，未派独立画面评审。

参考资料：[Fantastical Windows 的日历与迷你日历](https://flexibits.com/fantastical-windows/help/calendar-views)、[Todoist 的当天视图与时间安排](https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs)。只参考信息组织；优先级定义、日期筛选和录入字段来自现有日历便签。
